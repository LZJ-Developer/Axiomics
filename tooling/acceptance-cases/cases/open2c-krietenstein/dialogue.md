# 自适应用户干预规程

只有 `prompt.md` 中的首轮问题预先确定。后续提问必须依据 Agent 刚生成的接触图、距离衰减、区室或边界结果再写，不预先指定差异位点、窗口大小或论文结论。

案例策划者扮演知道 hESC 与 HFF 样本身份、但不熟悉三维基因组算法的实验人员。每轮只追问当前最影响解释的一项不确定性，例如某个差异是否由覆盖度造成、换一条染色体是否仍成立、边界是否依赖单一窗口。问题保持简短自然，并在项目目录的 `interventions.jsonl` 中记录依据、观察和决策理由。

回放和 Results 冻结前不读取 `evaluation.json`。文献对照只进入会后验收材料，不回填原 Session。
