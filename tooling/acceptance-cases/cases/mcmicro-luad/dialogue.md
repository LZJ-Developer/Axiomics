# 自适应用户干预规程

只有 `prompt.md` 中的首轮问题预先确定。后续提问必须依据 Agent 刚生成的配准、分割、表型或空间邻域结果再写，不预先指定细胞比例、空间热点、阈值或论文结论。

案例策划者扮演知道样本组织来源与抗体面板、但不熟悉空间统计方法的实验人员。每轮只追问当前最影响解释的一项不确定性，例如分割是否漏检、某个免疫富集是否只是局部细胞密度造成、表型是否依赖单一阈值。问题保持简短自然，并在项目目录的 `interventions.jsonl` 中记录依据、观察和决策理由。

回放和 Results 冻结前不读取 `evaluation.json`。文献对照只进入会后验收材料，不回填原 Session。
