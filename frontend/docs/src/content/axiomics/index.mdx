Axiomics is an AI workbench for scientific research. You give it a goal, and it works through the research loop the way a capable collaborator would: it reads the papers that matter, forms a hypothesis, writes and runs code, runs experiments on real compute, queries the major scientific databases, and writes up the result.

It runs as a workspace in your browser and works with frontier or open-weight models through your own API keys, provider subscriptions, or local endpoints. No Axiomics product account is required. It is model-agnostic and built to do real work in machine learning, biology, physics, and chemistry.

```bash
bun install
bun run setup
bun dev
```

`bun dev` opens the workspace in your browser. See [Quickstart](/axiomics/quickstart) for the full path from a checkout to a running session.

## Any model, your keys

Set an API key from any provider and start working. Keys stay on your machine.

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # or OPENAI_API_KEY, GEMINI_API_KEY, ...
bun dev
```

Axiomics routes to frontier and open-weight models from Anthropic, OpenAI, Google, and dozens of other providers. Reasoning-effort tiers are first-class: `--variant high|max|minimal` on any run. See [Models](/axiomics/models).

## Nothing leaves your machine

The agent loop, skills, database tools, and workspace all run from the same checkout. Projects, sessions, settings, credentials, results, and provenance stay on your device, and the local server binds to loopback only.

## Local by default

Connect only the providers and scientific services you want. Axiomics does not proxy model traffic or upload research traces.
