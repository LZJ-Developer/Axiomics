From a checkout to a running research session. Use your own provider account, API key, or local model.

<Steps>
  <Step title="Build">
    You need [Bun](https://bun.sh) 1.3.14 (the `packageManager` pin) and Node 18 or newer. From the repository root:

    ```bash
    bun install
    bun run setup
    ```

    `bun run setup` verifies Bun, installs dependencies, and builds the workspace UI once so `bun dev` can serve it. Rerun it with `--web` after UI changes.

    Linux requires kernel 5.1 or newer for the bubblewrap sandbox. On Linux ARM64, Bun-compiled executables currently require a 4 KB kernel page size.
  </Step>
  <Step title="Connect a model">
    ```bash
    bun dev keys add
    ```

    Choose a provider sign-in or save your API key locally. You can also skip this step and use a local model.
  </Step>
  <Step title="Choose model access">
    ```bash
    export ANTHROPIC_API_KEY=sk-ant-...   # or OPENAI_API_KEY, GEMINI_API_KEY, ...
    ```

    Any provider works — bring your own key and it stays on your machine. `bun dev keys add` gives you an interactive sign-in for providers that support it. See [Models](/axiomics/models) for routing and reasoning-effort tiers.
  </Step>
  <Step title="Open the workspace">
    ```bash
    bun dev
    ```

    This starts a local server and opens the browser workspace: file tree, editor, and session history, with inline rendering for molecules, structures, genomes, and plots. Pass a path to open a specific project. See [Workspace](/axiomics/workspace).
  </Step>
  <Step title="Give it a goal">
    Ask for the outcome, not the steps. The default `research` agent plans, reads, codes, runs, and reports:

    ```text
    Reproduce the headline result of arXiv:2305.13245 on a small model
    and tell me whether it holds at 125M parameters.
    ```

    Prefer your system terminal? One-shot runs work without the browser:

    ```bash
    bun dev run "Profile train.py and find the input-pipeline bottleneck"
    ```
  </Step>
</Steps>

## Verify the build

```bash
bun dev --version
bun dev models        # configured providers and models
bun dev skill list    # installed skills
```
