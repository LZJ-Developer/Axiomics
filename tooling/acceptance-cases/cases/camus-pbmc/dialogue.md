# CAMUS PBMC：真实多轮问题与复核

所有问题通过 Axiomics CLI 附着同一会话；未修改保存的对话。

## 第一轮：实际用户问题

我有一批健康人血液细胞的 ATAC 数据，还有一份标好细胞类型的 RNA 参考。想知道这些细胞分别是什么，但有些免疫细胞很像，我担心一种方法分错。你能用两种方法比较看看吗？先把整体情况和有分歧的地方给我看。

## 第二轮：根据返回结果追问

我最关心的是会不会把少量但重要的细胞漏掉。你说跨类分歧只有2%，这个比例是占全部细胞，还是只算有争议的细胞？另外，参考里有多少cDC，并不能说明这批里一定也该有那么多吧。能再仔细看看cDC和单核细胞这两处分歧吗？单核细胞的平均信号介于两边，会不会只是两种细胞混在一起，未必就是过渡态？最后帮我列清楚哪些可以先用，哪些先只保留大类、等后面验证，配几张一眼能看明白的图。

追问来源：第一轮的比例分母与科学解释不足，不使用事后作者标签。
